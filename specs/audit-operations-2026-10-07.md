## Runnable local mixed capacity contract

Run from the repository with Node 24 and locked installed dependencies:

```powershell
$env:CAPACITY_SECONDS='1800'
$env:CAPACITY_PORT='8820'
node tests/capacity-mixed.mjs
```

The runner creates a unique `.wrangler/capacity-mixed-*` copy, rewrites only that copy's resources to local dummy D1/private R2 identities, requires localhost, copies only the committed synthetic development secrets (rejecting a provider key), and uses only `--local`. It seeds 50 distinct synthetic users plus a **36,000-message synthetic twelve-month-volume fixture**, signs all 50 users in through the same localhost/shared-IP boundary in ten-account waves, performs 20/35/50 concurrent four-endpoint ramps and then mixes reads every five seconds, financial/write/upload lifecycle every 20 seconds and three overlapping test cron invocations each minute. The fixture's `historyMonths:12` labels modeled volume, **not uniformly distributed annual history**: message timestamps cover approximately 25 days around 340–365 days before seeding, at one-minute spacing. This limited distribution does not establish realistic production growth/read markers/seasonality. It also seeds delayed expired-hold fixture groups of 1/10/12/50, drains them through overlapping bounded ticks and requires one expiry event per hold. It checks actual replay transaction IDs rather than HTTP success alone. It reports endpoint p50/p95/p99, request/error counts, duration, write cycles, cron count and final date/ledger/effect/proof/slot/refund/integrity/FK invariants. Failed runs retain artifacts and stop the owned server. Independent parallel requests settle before failed-run recording so in-flight errors are retained.

Durable local output: each copy's `.wrangler/capacity-mixed-results.json`, `setup.log`, `server.log`, plus `.wrangler/audit-capacity-mixed-latest.json`. No Cloudflare billed rows, R2 billed operations, Worker CPU/memory, selected plan or headroom are invented: those fields remain null with an explicit scope statement. Existing short `tests/capacity.mjs` remains unchanged so normal CI verification does not inherit the 30-minute task.

This script is deliberately local-only. A staging operator must adapt the reviewed workload to the actual isolated target/controlled delivery contract; removing localhost or remote guards without reviewed mapping is not an acceptable staging setup. Independent injected-failure/response-loss tests are separate deterministic evidence. Real provider acknowledgement/DB-failure recovery, device behavior, platform restart and production observation remain separate gates.

The mixed lifecycle applies **one-booking disruptions**, and uses the small committed synthetic PNG proof; expiry fixture counts must not be mistaken for multi-booking disruption bursts. Near-limit/real-device image CPU/memory, disruption bursts 1/10/12/50, realistic annual timestamp/read-marker distributions and real shared-NAT arrival behavior on the intended plan remain missing G07 measurements even if the local soak passes.
